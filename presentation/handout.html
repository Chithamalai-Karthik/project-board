A plugin for Claude Code

Project board

Plan with your agent. Follow the work on a live board.

The plan lives in one file, ROADMAP.md, in the project: phases, steps and due dates. The agent writes it, works out the dates with a script, and keeps it up to date as the work happens. The board is a web page that shows that file as five columns, with a schedule timeline and overdue warnings. Nobody moves cards by hand. It also writes README.md, with a map of which file controls what, and AGENTS.md, the rules for any AI agent, and keeps both current.

What each of us gets

  • Developers: the plan updates while the agent codes. No extra tool, no tickets to move.
  • Managers: progress, dates and anything overdue at a glance, and "On track" or not.
  • Marketing: when launch is, what's next and what's waiting.
  • Designers: design steps and reviews on the board, with what they're waiting for.
  • Facilitators: a ready board for stand-ups, and a new schedule in one sentence.

Say it in plain words

Plan this project with the project board. A few questions, then phases, steps and dates. Step 4 is done. We're waiting for the design review. Put step 9 on hold: waiting for legal. We're behind: reschedule the rest. It shows the new end date first, and asks before changing it. Open the board.

Install it (once, in a terminal)

claude plugin marketplace add Chithamalai-Karthik/project-board
claude plugin install project-board@project-board

Then start a new Claude session. Updates: claude plugin marketplace update project-board, then claude plugin update project-board@project-board. In an editor's chat panel, /plugin isn't available: use the terminal.

Open the board

python board/serve.py

Run it in the project folder: it opens localhost:8790/board/ in your browser. It needs Python 3.8 or newer, and only your own computer can reach it.

No Claude Code? The board, its server and the scheduling script are copied into each project, so anyone with the project folder can open it.

Good to know

  • Dates are computed, not guessed: effort sizes S = 1, M = 3, L = 5, XL = 10 working days, on the days a week you work, minus days off.
  • Overdue shows the day after a due date; the timeline says "On track", "N overdue" or "Past the end date".
  • Decisions (a reschedule, a hold) are written into the roadmap with their date and reason.
  • Offline and private: no accounts, no database. Free under the MIT licence.
