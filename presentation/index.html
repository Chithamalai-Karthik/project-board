How it works

Plan, schedule, work, watch

1

Plan

The agent asks a few questions, then writes phases and steps a person can check.

2

Schedule

A script counts working days, days off and effort sizes. Every due date is worked out, none guessed.

3

Work

As work happens, steps become in progress, done, waiting or on hold, with the date.

4

Watch

The board shows it: columns, a timeline, overdue flags. Cards fly when they move.

The board's columns: To do Next In progress Done On hold

Under the hood

Simple by design

One Markdown file

ROADMAP.md sits in the project, next to the work. Readable by anyone, kept in version control.

One web page

The board is a single page that reads the file. It rereads it every minute while it's open.

Works offline

Opened with a tiny local server, on your own computer only. Nothing leaves it.

Nothing to sign up for

No accounts, no database, no subscription. Python 3.8 or newer is all it needs.

Works without the plugin

Each project gets its own copy of the board, so anyone can open it, with or without Claude Code.

Free and open

MIT licence. Use it, change it, share it.

Get started

Try it on your next project

Install, once (in Claude Code)

/plugin marketplace add Chithamalai-Karthik/project-board
/plugin install project-board@project-board

Open the board

python board/serve.py

From the project folder. It opens in your browser.

Then just say

Plan this project with the project board.
Step 4 is done.
We're waiting for the design review.
We're behind: reschedule the rest.
Open the board.
